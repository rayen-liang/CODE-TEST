# 個人程式學習平台

以 Streamlit 和 SQLite 建立，可整理、編輯及分享 Python、JavaScript 與 C++ 程式。
首頁預設使用深色主題，網站名稱為 MY CODE。

## 啟動

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

編輯密碼設定在 `.streamlit/secrets.toml`，此檔已列入 `.gitignore`，不會隨原始碼提交。部署至其他主機時，請透過該主機的 Streamlit Secrets 或 `APP_EDIT_PASSWORD` 環境變數設定編輯密碼，並妥善保護設定值。

程式資料預設存於 `programs.db`。分享連結供任何持有連結的人唯讀檢視；`localhost` 連結只適用於本機，需部署到可連線的主機才能分享給其他人。部署時請使用持久儲存空間並設定 `PROGRAMS_DB_PATH`，避免主機重啟後資料遺失。所有訪客必須連到同一個平台資料庫，才能看到相同程式。

## 功能

- 以巢狀檔案樹瀏覽根目錄、資料夾與程式檔。
- 首頁依「完成／未完成」分組，並在中央顯示近期編輯的程式。
- 編輯者可自訂首頁標題並釘選常用資料夾。
- 編輯者開啟程式時，左側保留首頁工具欄與檔案樹，頁面上方提供返回首頁與分享按鈕。
- 分享按鈕產生獨立唯讀連結；訪客只會看到程式名稱、上色後的程式碼與最近編輯時間，不顯示狀態、檔案樹或其他程式。
- 支援手動建立程式，以及在目前資料夾多選上傳原始碼檔。接受 `.py`、`.js`、`.cpp`、`.cc`、`.cxx`、`.c`、`.h`、`.hh`、`.hpp`、`.hxx`；每次最多 50 個檔案、合計 25 MB。上傳僅儲存 UTF-8 原始碼，不會執行檔案。
- 編輯程式碼時可即時查看依副檔名上色的 Python、JavaScript 和 C++ 語法預覽。
- 記錄檔案上傳時間、最近編輯時間，以及每次儲存前的程式碼、檔名與標籤版本。
- 編輯者可更新程式的「完成／未完成」狀態；舊資料庫會自動升級並保留現有程式。
- 支援新增、編輯和刪除資料夾或程式。
- 使用逗號分隔的標籤分類，並提供全文搜尋與標籤篩選。
- 訪客可唯讀檢視與分享；登入編輯密碼後才可修改內容。
